# Codex 用量小组件设计

**日期：** 2026-07-02  
**状态：** 已确认，进入实现  
**目标平台：** macOS 14+  
**设计基调：** 信息面板型，状态栏紧凑常驻，桌面小组件承担主要可视化信息

## 目标

构建一个全新的 macOS 小工具，用来随时查看 Codex 剩余用量。它提供两个展示层级：

1. 菜单栏常驻文本，默认显示 `5h 52% | 7d 42%`，不显示应用图标。
2. 桌面浮动小组件和展开面板，展示 5 小时窗口、7 天窗口、重置时间、刷新状态、套餐、Credits、刷新间隔和信息丰富度。

## 非目标

- 不读取 Codex Desktop 私有数据库。
- 不伪造真实额度；无法读取真实数据时显示模拟或不可用状态。
- 不实现审批、重置额度、修改 Codex 账户或替用户执行任何操作。
- 不做复杂登录流程；本次只实现可替换数据源接口和本地模拟数据。

## 展示规则

### 菜单栏

- 默认格式：`5h 52% | 7d 42%`。
- 分隔符固定使用 ASCII 竖线 `|`，两侧各一个空格。
- 不显示应用图标、终端图标、品牌图标或 mascot。
- 提供三种显示密度：
  - 极简：`52%`
  - 紧凑：`5h 52% | 7d 42%`
  - 详细：`5h 52% | 7d 42% | 02:27`

### 桌面小组件

- 主数字显示 5 小时窗口剩余百分比。
- 次要区域显示 7 天窗口、重置倒计时和数据新鲜度。
- 视觉风格为浅色磨砂玻璃、紧凑信息密度、绿色健康状态、琥珀色设置点缀。

### 展开详情

- 标题为 `Codex 用量`。
- 展示 5 小时窗口和 7 天窗口的进度条。
- 展示套餐、Credits、刷新状态、刷新间隔和信息丰富度。
- 信息丰富度影响详情文本数量，不改变菜单栏默认紧凑格式。

## 设置

- 刷新间隔：1、5、15、30 分钟，默认 5 分钟。
- 信息丰富度：简洁、标准、丰富，默认丰富。
- 菜单栏密度：极简、紧凑、详细，默认紧凑。

## 数据模型

核心模型使用不可变快照：

- `UsageWindowSnapshot`：一个额度窗口，包含窗口类型、剩余百分比和重置倒计时。
- `CodexUsageSnapshot`：完整 Codex 用量快照，包含窗口列表、套餐、Credits 和新鲜度。
- `WidgetSettings`：刷新间隔、信息丰富度和菜单栏密度。

真实数据源后续实现。当前版本提供 `MockUsageProvider`，用于原型展示和本地验证。

## 错误与降级

- 没有可用数据时，菜单栏显示 `Codex --`。
- 数据过期时，详情面板显示 `已过期`。
- 百分比会限制在 0...100，避免异常数据破坏 UI。

## 验收标准

- `MenuBarUsageFormatter` 能输出 `5h 52% | 7d 42%`。
- 菜单栏 UI 使用纯文本 label，不传入系统图标。
- 用户可以调整刷新间隔、菜单栏密度和信息丰富度。
- `swift test` 通过。
- `swift build` 通过。
