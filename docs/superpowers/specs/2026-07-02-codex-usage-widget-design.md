# QuotaBar Codex 用量组件设计

**日期：** 2026-07-02  
**状态：** 已实现并合并到 `main`  
**目标平台：** macOS 14+  
**产品名称：** QuotaBar  
**设计基调：** 状态栏紧凑常驻，展开面板承载详情，App 内桌面小组件用于持续可视化

## 目标

QuotaBar 是一个 macOS 菜单栏工具，用来查看当前 Codex 账号的剩余用量。它提供三种展示层级：

1. 状态栏文本：默认显示 `5h 52% | 7d 42%`，不显示应用图标。
2. 状态栏下拉面板：展示当前 5 小时窗口、7 天窗口、重置时间、刷新状态、套餐、Credits 和可用重置次数。
3. App 内桌面小组件：可浮动显示，也可通过设置吸附到桌面层级；它与 macOS 原生桌面组件设计共存。

## 非目标

- 不读取 Codex Desktop 私有数据库。
- 不伪造额度；无法读取真实数据时显示不可用或保留上一次可用快照。
- 不实现登录、审批、重置额度、购买额度或修改 Codex 账号。
- 不替用户执行任何批准或拒绝操作。
- 不承诺未签名构建能出现在 macOS 原生小组件库中；原生 WidgetKit 组件需要系统认可的签名与安装链路。

## 数据来源

当前实现通过 Codex app-server 的只读接口读取用量：

- 自动查找 ChatGPT 新版与 Codex 旧版 App 内的 `codex` 可执行文件，兼容系统级和用户级 `Applications` 目录
- 启动已找到的 `codex app-server --stdio`
- 调用 `account/rateLimits/read`
- 解析 `primary`、`secondary`、`credits`、`planType` 和 `rateLimitResetCredits.availableCount`
- 额度窗口优先按 `windowDurationMins` 识别：`300` 分钟映射为 5 小时，`10080` 分钟映射为 7 天；旧响应缺少该字段时才按 `primary`、`secondary` 位置兼容
- 5 小时限制临时停用时只展示真实存在的 7 天窗口；限制恢复后自动重新展示 5 小时与 7 天窗口
- 单次读取允许等待 app-server 初始化、插件和模型状态刷新；默认最多尝试 2 次，每次读取窗口 10 秒，避免 Codex app-server 偶发启动慢导致只收到初始化响应。

数据模型保留可替换 provider 边界：

- `UsageProviding`：数据源协议。
- `CodexAppServerUsageProvider`：真实只读数据源。
- `MockUsageProvider`：测试与降级展示用数据源。
- `CodexRateLimitResponseMapper`：把 app-server JSON 映射成快照。

## 数据模型

核心模型使用不可变快照：

- `UsageWindowSnapshot`：一个额度窗口，包含窗口类型、剩余百分比、重置倒计时和具体重置时间。
- `CodexUsageSnapshot`：完整 Codex 用量快照，包含窗口列表、套餐、Credits、可用重置次数和新鲜度。
- `WidgetSettings`：刷新间隔、信息丰富度、状态栏密度、是否显示 Codex 前缀、App 内桌面小组件是否吸附桌面、是否显示状态栏、是否显示 Dock 图标、是否开机启动。
- `RefreshScheduleFormatter`：格式化自动刷新倒计时和上次刷新时间。

快照会写入 `Application Support/CodexUsageWidget/usage.json`，供 WidgetKit 扩展读取。

## 状态栏

- 默认格式：`5h 52% | 7d 42%`。
- 分隔符固定使用 ASCII 竖线 `|`，两侧各一个空格。
- 不显示应用图标。
- 可选择是否显示 `Codex` 前缀。
- 提供三种显示密度：
  - 极简：`52%`
  - 紧凑：`5h 52% | 7d 42%`
  - 详细：`5h 52% | 7d 42% | 02:27`

## 状态栏下拉面板

- 标题为 `QuotaBar`，副标题说明数据来自 Codex 用量只读接口。
- 主数字优先显示 5 小时窗口剩余百分比，不存在时显示 7 天窗口。
- 只展示响应中真实存在的 5 小时或 7 天窗口进度条。
- 标准信息丰富度显示具体重置日期，不显示长倒计时；丰富模式同时显示易读倒计时与具体日期。
- 展示 Plan、Credits、Reset credits。
- 刷新状态块显示自动刷新间隔、距下次刷新、上次刷新时间和刷新中状态。
- 底部按钮为同等中性样式：桌面小组件、设置、刷新。
- 底部按钮不可聚焦，避免 macOS 焦点环误显示在错误按钮上；点击时只显示当前按钮按压反馈。
- 刷新读取 app-server 时必须等待初始化响应稳定，避免只收到 `id:1` 初始化结果而丢失 `id:2` 用量结果。

## 设置

设置页使用单一整页滚动，不使用顶部置顶和局部滚动。

- 顶部显示自动刷新状态和手动刷新按钮。
- 刷新间隔：1、5、15、30 分钟，默认 5 分钟。
- 自动刷新：默认开启；关闭后不在启动时读取用量，也不安排定时任务，只能通过手动刷新按钮读取。
- 信息丰富度：简洁、标准、丰富，默认丰富；对应预览放在该设置项附近。
- 状态栏密度：极简、紧凑、详细，默认紧凑；状态栏预览放在该设置项附近。
- Codex 字样：控制状态栏是否显示 `Codex` 前缀。
- 状态栏显示：控制是否创建 macOS 状态栏文本入口，默认开启。
- Dock 图标：控制是否以普通 App 形式显示 Dock 图标和应用菜单，默认关闭；设置窗口打开期间不即时降级为代理应用，关闭设置窗口后生效，避免设置窗口被系统收起。
- 开机启动：使用 macOS `SMAppService.mainApp` 注册或取消主 App 登录项；启动时同步系统登录项状态。
- 当状态栏显示关闭且 Dock 图标也被关闭时，应用自动保留 Dock 图标，避免用户失去设置入口。
- 状态栏显示切换保留同一个 `NSStatusItem`，隐藏时把标题清空并将长度设为 0，尽量保持状态栏顺序稳定。
- 桌面小组件：控制 App 内悬浮小组件显示或隐藏。
- 吸附桌面：控制 App 内悬浮小组件是否放到桌面层级。
- 原生桌面组件：提供安装和显示位置入口，但会明确提示未签名构建可能无法被系统小组件库收录。
- 退出应用：单独放在设置页底部，不与刷新用量放在一起。
- 菜单、状态栏按钮和 `Cmd + ,` 都复用同一个自建设置窗口，不再同时打开 SwiftUI 默认 Settings 窗口。
- 设置窗口可见期间应用临时使用普通前台激活策略，使 macOS 菜单栏显示 QuotaBar；窗口关闭后再按 Dock 图标设置恢复。
- App bundle 不声明 `LSUIElement`，否则系统会把它固定为代理应用，设置窗口打开时菜单栏仍会停留在上一个 App。

## App 内桌面小组件

- 主数字优先显示 5 小时窗口剩余百分比，不存在时显示 7 天窗口。
- 展示响应中真实存在的额度窗口、Plan、Credits、Reset credits。
- 宽度固定，高度按内容自适应，避免重置时间或信息丰富度变化时被裁切。
- 使用较实的浅色背景，降低壁纸透明度导致文字不可读的概率。
- 支持普通浮动层级与吸附桌面层级。

## 原生 WidgetKit 组件

项目包含 `CodexUsageNativeWidgetExtension`，用于读取共享快照并显示系统小组件。

当前限制：

- SwiftPM 手工打包和 ad-hoc 签名的 `.appex` 可能无法被 macOS 小组件库登记。
- `spctl` 拒绝未受信任 app 时，`pluginkit` 不会可靠收录扩展。
- 正式发布应迁移到 Xcode app-extension 工程或提供有效 Apple 签名链路。

## 图标与名称

- 应用名为 `QuotaBar`。
- 图标源文件为 `Resources/QuotaBar.svg`。
- 构建脚本把 SVG 生成 `.icns` 并写入 app bundle。
- 图标使用深色底、绿色 `Q`、代码符号和用量条表达“Codex 用量状态栏工具”。

## 错误与降级

- 没有可用数据时，状态栏显示 `Codex --`。
- 数据过期或不可用时，详情面板显示不可用状态。
- 百分比会限制在 `0...100`，避免异常数据破坏 UI。
- 刷新失败时不会清空已有快照，避免短暂失败导致 UI 闪成未连接。

## 验收标准

- `MenuBarUsageFormatter` 能输出 `5h 52% | 7d 42%`。
- 状态栏使用纯文本 label，不传入系统图标。
- 用户可以调整刷新间隔、菜单栏密度、信息丰富度、Codex 前缀、状态栏显示、Dock 图标、开机启动和吸附桌面。
- 没有可用快照时，状态栏占位仍尊重 Codex 前缀开关：关闭前缀显示 `--`，开启前缀显示 `Codex --`。
- 状态栏预览在没有真实快照时使用本地样例快照，保证密度和 Codex 前缀开关即时可见。
- `Cmd + ,` 只聚焦或打开同一个 QuotaBar 设置窗口，不产生多个设置窗口。
- 切换“状态栏显示”和“Dock 图标”不会触发设置递归写入或崩溃。
- 设置窗口打开时，macOS 菜单栏显示 QuotaBar，而不是上一个获取焦点的应用。
- 状态栏下拉按钮整块可点击，且不会显示错误焦点轮廓。
- 设置页中退出应用与刷新用量分离。
- `swift test` 通过。
- `swift build` 通过。
- `Scripts/build-app.sh` 能生成 `.build/QuotaBar.app`。
